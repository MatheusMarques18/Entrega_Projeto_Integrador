# Sistema de Controle de Estoque — Marques Construções

## Sobre o projeto

Este projeto foi desenvolvido como parte do Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas (ADS) da UNISA.

A ideia surgiu da necessidade de organizar melhor os materiais utilizados na construção civil. O controle de estoque é importante para acompanhar os materiais disponíveis e facilitar a consulta das quantidades registradas.

Pensando nisso, foi desenvolvido um sistema simples em Python para auxiliar no controle dos materiais da Marques Construções, permitindo cadastrar, consultar, buscar e organizar os itens do estoque.

## Funcionalidades

O sistema possui as seguintes funcionalidades:

- **Cadastro de materiais:** permite registrar o nome do material e sua quantidade.
- **Consulta de estoque:** permite visualizar os materiais cadastrados.
- **Ordenação por nome:** organiza os materiais em ordem alfabética, facilitando a localização dos itens.
- **Busca de materiais:** permite procurar um material cadastrado.
- **Armazenamento de dados:** utiliza um arquivo de texto para manter os registros salvos mesmo após o encerramento do programa.

## Tecnologias que estão sendo utilizadas 

- Python 3, para o desenvolvimento do sistema.
- Visual Studio Code, como ambiente de programação.
- Arquivo de texto (`estoque.txt`), para armazenar os dados do estoque.

## Como executar o sistema

Para utilizar o programa, siga estas etapas:

1. Baixe o projeto pelo GitHub.
2. Verifique se o Python 3 está instalado no computador.
3. Mantenha os arquivos `main.py` e `estoque.txt` na mesma pasta.
4. Abra a pasta do projeto no Visual Studio Code.
5. Execute o arquivo `main.py` para iniciar o sistema.

## Arquivos do projeto

- `main.py`: contém o código principal e as funcionalidades do sistema.
- `estoque.txt`: armazena os nomes dos materiais e suas respectivas quantidades.
- `teste_ordenacao.py`: contém um exemplo utilizado para verificar a lógica de ordenação dos materiais.

## Considerações finais

O desenvolvimento deste projeto permitiu aplicar conhecimentos de programação em Python na construção de uma solução para uma necessidade prática da construção civil. Além disso, o trabalho contribuiu para o aprendizado sobre organização de dados, estruturas de repetição, condições e manipulação de arquivos.

O sistema foi pensado como uma ferramenta simples de apoio ao controle de estoque da Marques Construções, podendo receber melhorias futuras conforme novas necessidades forem identificadas.
